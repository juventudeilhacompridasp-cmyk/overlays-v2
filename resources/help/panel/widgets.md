Em [Widgets](route:panel.widgets.index) você gera o código para incorporar no site da organização, sem login para o visitante:
- **Placar ao vivo** de um jogo.
- **Classificação** de uma divisão (com número de linhas).
- **Jogos** de uma edição.

## Como usar
1. Escolha o widget, o tema (claro ou escuro) e a cor de destaque.
2. Copie o código (um `iframe`, com um script opcional que ajusta a altura sozinho).
3. Cole na página do seu site.

Só edições **publicadas** aparecem. Os widgets podem ser incorporados em qualquer site; as demais páginas do portal só abrem dentro do próprio domínio.
